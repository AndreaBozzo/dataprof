Know your data before it ships.

Profile CSV, JSON, JSONL, Parquet, DataFrames and Arrow in one call: types, nulls, distributions, patterns and a quality score. Then gate your pipeline on what it found. It runs locally, records what it analyzed, and says “can’t tell” when the evidence is insufficient.

Quickstart

Profile, then gate

A Python package for notebooks, scripts and CI, and a Rust crate for services and batch jobs. Save orders.csv beside your script to reproduce the report above.

uv pip install dataprof 
import dataprof as dp

report = dp.profile("orders.csv")
print(report.quality_score)  # 93.19
region = report["region"]
print(region.null_percentage)  # 25.0

result = report.check(
    min_quality_score=90,
    max_null_percentage={"*": 20},
)
print(result.verdict)  # fail

# Save the full report for later.
report.save("report.json")
context = report.to_llm_context(
    max_tokens=500,
)
print(context)

In CI: python -m dataprof.check orders.csv --min-quality 90 --max-null "*=20" exits 1 for this CSV. Exit codes are 0 for pass, 1 for fail, 2 for inconclusive, and 3 for an input, policy or output error. Wheels for CPython 3.11 to 3.15 with no Python dependencies; pandas is optional, for DataFrame-typed exports. See the Python API guide.

cargo add dataprof 
use dataprof::Profiler;

let report = Profiler::new()
    .analyze_file("orders.csv")?;
println!(
    "Rows: {}",
    report.execution.rows_processed,
);
println!(
    "Quality: {:?}",
    report.quality_score(),
);

for col in &report.column_profiles {
    println!(
        "{} {:?} nulls={}",
        col.name,
        col.data_type,
        col.null_count,
    );
}

MSRV 1.96. Feature flags cover Arrow, Parquet, async streaming, and PostgreSQL / MySQL / SQLite connectors. For a smaller build, use default-features = false. See docs.rs.

What you can count on

Careful numbers, bounded memory

Metrics checked across inputs

CI compares serialized metrics across input paths and engines against a shared numeric contract, which defines precision and known limits.

Bounded memory

The incremental engine reads chunks into bounded accumulators. Distinct counts stay exact up to a million values, then become estimates marked in the report.

Multi-format by default

CSV, JSON, JSONL, Parquet, pandas and polars DataFrames, and Arrow tables and streams share a report model. Database connectors are available in source builds.

Verdicts that can say “can’t tell”

Gates return pass, fail or inconclusive. Whole-source ratio checks stay inconclusive on partial scans; sampled quality scores carry bounds.

Unassessed metrics stay missing

A metric that was not computed is reported as missing, never as a plausible default. Findings list the rules they could not evaluate.

Report context for agents

to_llm_context() produces a token-bounded summary of counts, patterns and quality evidence, with no raw cell values.

ISO 8000-8 · ISO/IEC 25012

Quality scores with the evidence behind them

When quality analysis is requested, dataprof assesses up to seven dimensions informed by international data-quality standards. Its configurable aggregate score uses only the dimensions the data could actually support.

Completeness

Missing-cell percentage, share of fully-populated rows, columns past the null threshold.

Consistency

Data type consistency, format violations, encoding issues.

Uniqueness

Duplicate rows, key uniqueness, high-cardinality warnings.

Accuracy

Outlier ratio, range violations, negatives in positive-only columns.

Timeliness

Future dates, stale-data ratio, temporal ordering violations.

Validity

Conformance to confidently detected semantic patterns, with weak evidence left unassessed.

Precision

Consistency of observed decimal scale within floating-point columns.
